# 工作日志 2026-03-14 第1次

## 完成内容：Phase 1 — 参考文献生成器 MVP

### 1. 项目初始化
- 使用 Vite + React 18 + TypeScript 创建项目骨架
- 安装并配置 Tailwind CSS v4（@tailwindcss/vite 插件）
- 安装 citeproc-js 用于 CSL 格式化
- 配置 `index.html`（中文语言、项目标题）
- 配置 `vite.config.ts`（React + Tailwind 插件）
- 清理 Vite 默认模板文件

### 2. 核心数据模型 (`src/core/`)
- **types.ts** — 定义 CSL-JSON 兼容接口：CslItem, CslName, CslDate, CslItemType, CitationStyle, FieldSchema, ParseResult
- **constants.ts** — 9种文献类型（期刊/图书/会议/学位论文/报告/报纸/标准/专利/电子资源）的字段 schema；8种引用格式定义；GB/T 7714 ↔ CSL 类型映射；工具函数 generateId/createEmptyCslItem
- **nameUtils.ts** — 中英文作者姓名解析（支持30+复姓、英文"LastName, First"格式等）；parseAuthorName, parseAuthors, formatCslName, formatCslNames

### 3. 格式化引擎 (`src/core/formatter/`)
- **styleLoader.ts** — CSL 样式/locale XML 按需加载与缓存
- **citeprocEngine.ts** — citeproc-js 封装：createSysAdapter, formatWithCiteproc, formatMultipleStyles, cleanHtml
- **index.ts** — 公开 API：formatCitation, formatAllStyles, preloadCommonStyles
- **citeproc.d.ts** — citeproc 模块类型声明

### 4. CSL 资源文件 (`public/`)
- `csl-styles/`: apa.csl, ieee.csl, modern-language-association.csl, chicago-fullnote-bibliography.csl, vancouver.csl, harvard-cite-them-right.csl, chinese-gb7714-2005-numeric.csl, chinese-gb7714-2005-author-date.csl
- `csl-locales/`: locales-zh-CN.xml, locales-en-US.xml

### 5. UI 组件 (`src/components/`)
- **builder/TypeSelector.tsx** — 文献类型选择器（左侧栏，9种类型带图标和GB/T代码）
- **builder/AuthorListEditor.tsx** — 多作者编辑器（增删排序、中英文智能解析、回车添加）
- **builder/CitationForm.tsx** — 动态表单（根据文献类型显示不同字段，必填/选填折叠）
- **builder/FormatSelector.tsx** — 输出格式多选器（圆角标签样式，支持全选）
- **builder/OutputPanel.tsx** — 结果展示面板（多格式输出、单条/全部复制）
- **builder/BuilderView.tsx** — 三栏布局主视图（类型选择 | 表单 | 输出）
- **shared/CopyButton.tsx** — 复制按钮（带反馈动画，降级方案）

### 6. 应用框架 (`src/`)
- **App.tsx** — 顶部导航栏（生成/转换 tab 切换）+ 主内容区 + 底部
- **index.css** — Tailwind 主题配置（Apple 风格色彩、中文字体栈）
- **main.tsx** — React 入口

### 7. 验证
- TypeScript 类型检查通过（tsc --noEmit）
- Vite 生产构建成功
- 开发服务器正常启动并渲染页面
