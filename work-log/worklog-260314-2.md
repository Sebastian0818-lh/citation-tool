# 工作日志 2026-03-14 第2次

## 完成内容：Phase 2 — 格式转换器 + AI 解析

### 1. 格式自动检测 (`src/core/parser/detectFormat.ts`)
- 支持检测 9 种格式：BibTeX, RIS, CSL-JSON, GB/T 7714, APA, IEEE, MLA, Chicago, Vancouver
- 每种格式有特征正则匹配，返回格式名 + 置信度评分
- BibTeX 通过 `@` 前缀识别，RIS 通过 `TY  -` 识别
- GB/T 7714 通过 `[J]`, `[M]` 等类型标记识别
- APA 通过 `(年份).` 模式识别，IEEE 通过 `[数字]` 前缀识别

### 2. 各格式解析器 (`src/core/parser/`)
- **gbtParser.ts** — GB/T 7714 解析器
  - 按类型标记分割"作者.标题" vs "来源信息"
  - 每种文献类型（J/M/C/D/N/P/EB-OL 等）有专门的来源解析逻辑
  - 提取期刊名、卷期、页码、出版社、年份、URL、DOI 等
  - 每个字段附带置信度评分
- **apaParser.ts** — APA 解析器
  - 核心模式：`作者 (年份). 标题. 来源`
  - 自动区分期刊文章 vs 书籍
  - 提取 DOI/URL
- **ieeeParser.ts** — IEEE 解析器
  - 核心模式：`[N] 作者, "标题," 来源`
  - 提取 vol./no./pp. 等字段
  - 支持期刊和书籍两种模式
- **genericParser.ts** — 启发式通用解析器
  - 按句号分段，猜测作者/标题
  - 提取年份、DOI、URL、卷期、页码
  - 置信度上限 0.5，提示用户审核

### 3. 统一解析入口 (`src/core/parser/index.ts`)
- `parseCitation(text)` — 自动检测格式 → 选择对应解析器 → 返回 ParseResult
- `parseCitations(text)` — 批量解析（按空行分隔）
- 未识别格式时依次尝试各解析器，最后回退到通用解析器

### 4. AI 辅助解析模块 (`src/core/ai/`)
- **prompts.ts** — 结构化 prompt 模板，指示 AI 输出 CSL-JSON 格式
  - 详细说明中英文姓名处理规则
  - 指定所有字段及其含义
- **providers.ts** — OpenAI 和 Anthropic (Claude) 双 provider 适配
  - 支持自定义模型和 API 端点（用于代理或自部署）
  - OpenAI 默认 gpt-4o-mini，Anthropic 默认 claude-sonnet
  - Anthropic 支持 `anthropic-dangerous-direct-browser-access` 头
- **index.ts** — AI 解析公开 API
  - `parseWithAi(text, config)` — 调用 LLM 解析引文
  - 智能 JSON 提取：直接解析 / markdown 代码块 / 花括号定位
  - `loadAiConfig() / saveAiConfig() / clearAiConfig()` — localStorage 持久化
  - AI 解析置信度固定为 0.8

### 5. 转换器 UI (`src/components/converter/`)
- **ConverterView.tsx** — 三步流程 UI
  - Step 1（输入）：粘贴区 + 实时格式检测徽章 + "智能解析"和"AI 解析"双按钮
  - Step 2（审核）：左侧显示原文+总体置信度进度条，右侧可编辑字段表单
  - Step 3（输出）：格式化结果展示 + 复制
  - 步骤指示器、错误提示、重新开始按钮
- **FieldReviewForm.tsx** — 可编辑字段审核表单
  - 每个字段左侧有置信度彩条（绿/黄/红）
  - 文献类型可切换，字段根据类型动态调整
  - 复用 AuthorListEditor 组件
